Steady Refresh privacy policy

This policy covers the Steady Refresh Chrome extension only. Last updated 17 November 2026.

What the extension collects

Nothing. Steady Refresh does not collect, send, sell or share any personal or browsing data. It has no account, no analytics and no advertising, and it makes no network requests of its own.

What it reads, and why

Steady Refresh only reads a page on sites you have allowed in Chrome's permission prompt, and only to do what you turned on:

  • Alerts. It checks the page text for the words you entered. The check happens inside your browser, and the page text is not stored or sent anywhere.
  • "Page changes" alerts. It keeps a short fingerprint (a hash) of the page text so it can tell when the text changes. The fingerprint cannot be turned back into the text, and it is deleted when you close the browser.
  • Pause while you use the page. It notices that you typed, clicked or scrolled. It does not record what you typed or where you clicked.
  • Keep scroll position. It remembers how far down the page you were, in that tab only, until the next reload.

The current tab's address is read when you open the popup, so the popup can show the site name and save a page you ask it to start on automatically.

What it stores

Your settings and the pages you chose to start automatically are kept in Chrome's local extension storage on your computer. The state of running timers is kept in session storage and cleared when you close the browser. Removing the extension deletes all of it. Export writes a backup file only when you click Export, and only to your computer.

Links

The settings page links to Steady Refresh's own Chrome Web Store page, for reviews and support. Nothing is sent when you open it; it is an ordinary visit to that page.

Third parties

None. No data is shared with anyone.

Limited Use

The use of information received from Chrome APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Changes

If a future version changes what is read or stored, this page will be updated before that version is published.
