A 30-second check catches missed reloads

Chrome puts idle extensions to sleep, and a lot of auto-refreshers lose their timer when that happens. The countdown keeps showing, but the page never reloads.

Steady Refresh keeps its schedule in Chrome's storage and checks every 30 seconds that each tab is on time. A missed turn gets made up, and a page that hangs while loading is tried again.

Example: a tab set to reload every 5 minutes
  1. 09:00:00Reloaded
  2. 09:05:00Reloaded
  3. 09:10:00Missed while Chrome was asleep
  4. 09:10:30Caught up by the 30-second check
  5. 09:15:00Reloaded, back on schedule

Pause, scroll and hours, one switch each

It waits while you're typing, keeps your place on the page, and only runs when you want it to. Every option is one switch in the popup.

Pause while I'm using the pageCarries on 15 seconds after you stop typing, clicking or scrolling
Keep my scroll positionReturns to the same spot after each reload
Alert meWhen text appears, disappears, or anything on the page changes
Only during set hoursWith a weekdays-only option
Start automatically on this pagePicks up again the next time the address opens

No account and no network requests

The text on your pages is checked on your own computer. Site access is asked for one site at a time, and only for the features that need it.
